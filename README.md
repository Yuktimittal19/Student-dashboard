# 🎓 Student Life Dashboard

Hey there! 👋 Welcome to my upgraded Student Life Dashboard.

What started as a simple Python Tkinter project has now transformed into a full-fledged local productivity tool. I built this to manage my daily college tasks, track expenses for my Master's study fund, and jot down quick thoughts—all offline, with a sleek dark-mode UI and zero cloud dependencies.

## ✨ What's New & Core Features

The dashboard is split into three main modules:

*   **📝 Task Manager with Analytics:** 
    *   Add tasks with descriptions, Priority (High/Med/Low), and Due Dates.
    *   **Smart Highlighting:** Tasks that cross their deadline automatically turn **RED**.
    *   **Live Graph:** A real-time updating pie chart showing the ratio of 'Done' vs 'Pending' tasks.
    *   **Export:** One-click export to CSV for your records.

*   **💰 Finance & Goal Tracker:** 
    *   Log daily expenses by amount and category.
    *   **Custom Goal Tracker:** Set and update your long-term savings goal (saved permanently).
    *   **Live Graph:** A real-time pie chart breaking down your expenses by category (e.g., Food, Travel, Books) so you know exactly where your money is going.
    *   **Export:** Download your monthly expense report as a CSV file.

*   **🗒️ Quick Sticky Notes:** 
    *   A 3-grid sticky note system for instant scratchpad use. Write down code snippets, random ideas, or phone numbers, and hit save. It stays there even after you close the app.

## 🛠️ Tech Stack
*   **Python 3** (Core Logic)
*   **Tkinter** (Base GUI)
*   **ttkbootstrap** (For the sleek, modern dark-mode UI)
*   **Matplotlib** (For rendering live data visualization graphs)
*   **JSON & CSV** (For lightweight local data storage and exporting)
